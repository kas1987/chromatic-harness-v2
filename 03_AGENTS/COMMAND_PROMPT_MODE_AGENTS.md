# Agent Assignments: Command Prompt Mode System

## Architect Agent

Owns PDR integration, source-of-truth reconciliation, and README update.

## Protocol Agent

Owns `01_PROTOCOLS/COMMAND_PROMPTS/` and schemas.

## Frontend Agent

Owns Command Center mode switcher, asset pack loading, and panel prioritization.

## Auditor Agent

Verifies implementation against PDR, schemas, and `CHROMATIC_TREES.md`.

## Scribe Agent

Updates docs, handoffs, Beads, and implementation logs.

## Security Agent

Verifies mode-specific forbidden tools, forbidden paths, and mutation controls.
