# Mission Review Checklist

- [ ] Mission ID exists
- [ ] Mission level is correct
- [ ] Objective is measurable
- [ ] Scope is clear
- [ ] Out-of-scope is clear for M2+
- [ ] Acceptance criteria are testable
- [ ] Dependencies are identified
- [ ] Risks are identified
- [ ] Rollback is appropriate for level
- [ ] Tool budget is assigned
- [ ] Stop conditions are listed
- [ ] Approval requirement is correct
- [ ] Validation strategy is sufficient
